# Hotpot dataset retention cleanup manifest
#
# Syntax: repository-root-relative, Gitignore-style paths. A trailing slash
# selects the directory and all of its contents. This file is declarative; no
# Hotpot command executes it automatically.
#
# These paths become eligible for deletion only after the dataset owner has:
# 1. ended the applicable retention period;
# 2. retained an external archive, or explicitly waived restoration;
# 3. verified that store/active resolves to stage13-compact-current;
# 4. run `hotpot ds detail audit` successfully;
# 5. accepted that deleting a migration Bundle prevents loading that Bundle or
#    reconstructing it from its root certificate without restoring the archive;
# 6. preserved current-inventory.json, the compact and efficiency rebuild
#    parity/activation records, stage13-cutover.json, migration-report.json,
#    migration-plan.json, and store/certificates/; and
# 7. recorded the deletion as an owner-approved retention event.
#
# Never add the active generation, its asset store, source datasets, structure
# sources, current audit reports, or current certificates to this manifest.
