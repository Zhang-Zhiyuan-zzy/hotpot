## 4. 校验标准：围栏、等价、近似与随机性

| 对象 | 标准 | 失败与可用观察的边界 |
|---|---|---|
| 确定性事实与完整性 | 同一原子的元素/同位素、端点和归属映射必须正确；未授权化学变化不得增删原子、H、键语义或电荷；预期反应/质子化/电子转移按该操作声明判断 | 错配、静默丢数据、错误单位、回滚破坏等需局部拒绝；可独立样本继续 |
| 化学表示等价 | 在明确原子映射和所选表示约定下比较；不把原子顺序、SMILES文本、芳香/Kekulé写法不同自动判错；不可把不同对映体当等价 | 对用户权威事实的重写仍需禁止；“等价”不是忽略真实立体或配位语义差异 |
| 数值结果 | 先统一量纲、状态、方法与可比对象；按字段使用绝对+相对误差，例如abs(a-b)≤atol+rtol×max(abs(a),abs(b))。容差由格式精度、算法收敛、dtype、尺度和用途决定，运行前写明 | 不通用套1e-8、不看结果后调容差；超差先归因，不能用宽容差吞掉单位、映射或化学错误 |
| 几何 | 需要时允许平移/正确旋转及合法对称原子置换；联合看RMSD、最大位移、局部几何和手性；轨迹不同不等于错误 | 手性比较不允许镜像把对映体叠成同一结构；穿环、碰撞等按具体检查域、数值边界和配置处理 |
| 能量/梯度 | 比较相同方法、组成、电荷、自旋、单位和能量参考；保存有限观察和必要收敛信息 | 非有限能量不能冒充有效能量；高但有限的能量只有在有效参考/阈值下产生finding，不能自动证明结构不存在 |
| 随机或并行计算 | 记录seed、方法、模型和有效参数；必要时用多seed/重复观察，比较任务结果分布、硬规则违反、稳定性与效应范围 | 不要求逐帧/逐位等同，不强求历史182成功数；CI重叠不自动证明等价，偶发一次差异也不自动证明回归 |
| MCA模型值与位点 | 原子/位点身份、形状、基数和单位严格；同模型/设备可比数值用有根据的误差；模型变更另作归因 | 模型输出是该模型的估计，不为每个值附加虚构科学置信等级；预测值改变不自动是bug |
| 科学围栏 | 电子数/自旋合法性、数据归属、非有限值等按命名规则域检查；几何/价态/能量启发式需保留约定和适用域 | 操作性拒绝不宣称普适化学不可能；异常样本局部失败，finite可解释观察按策略保留，warning/break与finding内容分开 |

NumPy官方allclose文档明确默认atol不适用于所有小尺度数值；PyTorch官方Reproducibility文档说明跨版本、平台及CPU/GPU不能普遍保证完全复现。这些资料支持“按具体方法与用途选容差和复现目标”，不替Hotpot提供一个通用数值阈值。这里未声称所有上述新标准已被当前测试实现。

## 5. 后续如何兼顾推进与可靠性

1. 每个业务切片先明确会改变什么事实、允许哪些科学差异、违反哪些命名规则必须拒绝，再写实现和少量能识别这些错误的检查。保留已有有效回归，不为覆盖数量写镜像测试。
2. CP311先形成1–4项的真实闭环。5–6先保核心用路；7的独立问题登记后暂缓。测试分类优先于大而全的跨版本/反射/归档矩阵。
3. SHA与来源记录在运行边界用于归因；不重建一套放行体系。对已知校验器故障，记录其故障，使用可解释的原始结果或轻量直接命令。没有可信结果的业务仍记未验证，不伪造pass。
4. 不再把“707→985→fresh26→完整profiler工具链”整体当作继续主线的必经串行关卡。按实际业务风险选择证据；985中仍有价值的无修改/无损运输检查可直接复用，而非一概删除。
5. 性能先做小型代表工作量和资源检查，选高效批处理/局部复用；没有可运行性、资源或吞吐灾难时，允许可解释退化带着记录进入下一阶段。用户举的约5倍是可接受情境示例，不编造成所有任务统一5.000倍硬阈值。OOM、资源无界增长或大批次不能完成仍关乎业务可靠性，需要处理。
6. 其他Python版本后续集中适配；已通过且输入未变的结果继续复用。最终明确真实支持范围和未执行项，不把延期验证写成兼容成功。
7. GTD候选若只解决性能问题，可连同深层native追溯后置；先用真实可安装的CP311路径验证必须业务。私有候选证据不能冒充已交付的依赖修复。
8. 每次推进以“实现+必要验证+局限记录”的完整小结果提交并推送。简要记录证据入口，保留原始失败；不再为每条准备/调度状态新建细碎提交。
